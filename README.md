# CareerBridge

CareerBridge is an Android-based career guidance and placement preparation application designed to support students in their career development.

## Project

CareerBridge provides a platform for students to manage their career-related activities and access useful placement preparation resources.

## Technology Used

- Android Studio
- Kotlin
- XML
- Git & GitHub

## Platform

Android

v0.0 – Demo Release
